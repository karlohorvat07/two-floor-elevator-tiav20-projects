🛗 2-Floor Elevator — Siemens TIA Portal

A 2-floor elevator control system created as a personal project while independently learning PLC programming and industrial automation with Siemens TIA Portal.

📖 Project Overview

The project simulates the basic operation of a two-floor elevator controlled by a Siemens PLC.

The PLC handles elevator movement, floor requests, position detection and safety/interlock conditions.

The goal of this project was to practice creating a complete control sequence rather than programming individual PLC exercises.

⚙️ Main Functions
Elevator movement between Floor 1 and Floor 2
Floor selection/request buttons
Floor position detection
Up/down motor control
PLC interlocks
Prevention of unsafe motor commands
Elevator status indication
🧠 What I Learned

While developing this project, I practiced:

PLC programming with Siemens TIA Portal
Creating sequential control logic
Working with digital inputs and outputs
Sensors and limit switches
Motor control logic
Safety interlocks
Function Blocks and Data Blocks
Troubleshooting PLC logic
Testing and simulation

Most importantly, this project helped me understand how multiple PLC conditions and sequences work together as one automated system.

🔄 Basic Sequence
Passenger selects a floor.
PLC checks the elevator's current position.
Elevator starts moving in the required direction.
Floor sensor detects arrival.
Motor stops.
Elevator waits for the next request.

🛠 Software
Siemens TIA Portal v20
PLCSIM v20

🎯 Purpose

This project was created independently as part of my self-learning in PLC programming and industrial automation.

It is an educational project and is not intended to control a real passenger elevator or safety-critical system.
